

this experiment aims to test whether turn off the wind will enhance the submesoscale fields or weak the submesoscale fields. 

we set the start time point as: 26604288
we turned off the wind, and run till time step at 26624160 , then compare the submesoscale heat flux with the simulation results which has the wind stress.

We compared the submesoscale field after few hours when turned off the wind, few days, and 100 days, all the results shows that turning off the wind will only weak the submesoscale fields.
