# SubmesoFluxNet architecture

The final SubmesoFluxNet architecture schematic used in the manuscript was
created manually in LaTeX using Overleaf. It is not generated by a Python
plotting script in this repository.

The Python script in this directory generates the example input and target
fields used as graphical elements in the schematic:

- `plot_upper_40x20_input_fields.py`

The authoritative model implementation is located at:

- `src/submesofluxnet/model.py`

The corresponding architecture and training settings are defined in:

- `config/config.yaml`
