# Architecture Feature Maps

Clean standalone PNGs for the four bottleneck feature maps used in the model schematic.

These images have no axes, no boundary, no title, and no colorbar.

Run from `_src`:

```bash
source ../setup
python analysis/explanability/bottle_feature/architecture_feature_maps/plot_architecture_feature_maps.py
```

Outputs:

```text
bottleneck_feature_1.png
bottleneck_feature_2.png
bottleneck_feature_3.png
bottleneck_feature_4.png
selected_sample.txt
```
